两条路，都通往好日子

你先看完再选。选了就别回头，剩下的交给我们。
你初筛合格，两条路都走得通。
不存在"一条不行换另一条"——两条路是并列的，各有各的好，各有各的苦。

而且不管选哪条，你未来的收入都会超过很多挤普通大学的人。
因为你的赛道竞争小、技术壁垒高，市场上抢着要。

第一条路：服装表演/航服艺考 → 公办本科

你得到什么

  • 学历：公办本科。东华大学（211）、北京服装学院、重庆师范大学、四川外国语大学、重庆工商大学——都是正经本科。
  • 文化课要求：2024年重庆服装表演文化课最低控制线是 320分（满分750），比普通本科线低了100多分。但专业统考最低也要 210分（满分300），两个分都必须过线。
  • 毕业以后：模特、电商主播、空乘（空少）、形体老师、秀场编导。但这些岗位需求总量不大，淘汰率高。
  • 收入参考：大部分毕业生 5K-10K/月。能做到头部主播/名模的很少。
  • 就业面窄：除了对口那几类岗位，很难转行。

你要扛什么

这条路最难的不是考试，是训练。

— 你有高低肩、脊柱有点弯、走路姿势不对。这些东西必须靠每天训练去掰过来。
— 每天贴墙站15-30分钟。后脑勺、肩胛骨、屁股、脚跟四点贴墙。前一周站5分钟就发抖，两周后能站15分钟。目的就是把脊柱拉直、肩膀调正。
— 步态训练每天2小时以上。胯带腿、肩不动、脚的角度精确到度数。第一天腰腿酸痛到想骂人。脚上起水泡是正常的，长茧了就好了。
— 体脂率要控制在12%以下。零食基本戒掉。不是单纯瘦，是要有肩背线条。
— 前3个月最难熬。很多人在这时候放弃。扛过去后面就是重复和打磨。
— 同时还要扛文化课。高二每天训练完还要背单词、背古诗。两条线一起走，比别人多花一倍的功夫。
— 选了这条路，你高二高三基本没有周末。别人休息的时候你在站墙、走步、控体重。

第二条路：硬核技术流 → 公办好大专/职业本科

你得到什么

  • 学历：重庆工业职业技术大学、重庆电子科技职业大学（都是公办本科层次职业大学），或者重庆工程职院、重庆航天职院（公办双高大专）。
  • 还可以去北上广深：深圳职业技术大学（全国第一·已升本科）、广东轻工职业技术大学、北京电子科技职业学院（奔驰/百度订单班）、上海电子信息职业技术学院——但去这些地方要走夏季高考。
  • 毕业以后：工业机器人调试工程师、新能源汽车检测工程师、PLC编程、智能产线运维。
  • 收入参考：重庆毕业 8K-12K/月，3年经验 15K-22K/月，5年技术主管 25K-40K/月。
  • 去沿海更高：深圳/上海同类岗位起步就是 15K-20K/月，干了5年月入3万+很普遍。越老越值钱。

你要扛什么

这条路最难的不是训练，是坚持和学习。

— 不走艺术路线，文化课不能再"断舍离"。数学、英语、技术三门都要硬啃。
— 数学：集合、复数、数列、概率这些基础题型，每天刷。不求高分，基础分必须拿稳。
— 英语：死背1500个核心词汇。分类考试不考听力，纯靠词汇量吃饭。
— 技术科目（300分！）：信息技术和通用技术占300分（满分750），这是最容易拿分的科目。背熟概念就能拿高分。
— 春季考+夏季考都要准备。3月考分类考试，没录好6月继续。
— 这条路的苦是"磨"出来的。没有走路的酸痛，但有每天刷题、背单词的枯燥。
— 但好处是：不用额外花钱参加艺考培训，日常就在学校上课。4月如果分类考试录了，高三直接提前毕业。

选艺考 → 你条件达标，训练虽然苦但有希望。但你要清楚：这个行业只留得住最顶尖的人，大部分人干几年就得转行。

选技术 → 这是未来10年的大方向。国家在砸钱搞智能制造，人才缺口几十万。你学会一门硬技术，走到哪都不愁饭吃。而且——当你的同学还在为毕业季找工作发愁时，你已经是奔驰/百度订单班出来的准员工了，月薪起步过万。

春季分类考和夏季高考都去考。
→ 春季考得好 → 4月被重庆本地好学校录走，提前上岸
→ 春季没录好 → 6月继续用夏季高考冲北上广深的学校
→ 再考不好 → 还有很多学校可以去，公办好大专门槛没那么高

不管考成什么样都有学上。而且学出来的收入，不会输给任何一个普通本科生。

全国智能工厂都在上自动化产线，工业机器人、新能源汽车的人才缺口是几十万级别。
未来10年，技术工人比坐办公室的白领更好找工作、工资更高。这是国家产业升级的方向。

当你的初中同学本科毕业出来挤人才市场时，你已经有3年行业经验了。3年经验的技术工人在深圳，月薪3万+是常态。
不管你选哪条路，从高二开始每天都要在学。
选艺考：每天站墙+走步+背单词+控体重
选技术：每天刷数学+背单词+背技术概念
坚持一年半，都能上岸。三天打鱼两天晒网，哪条路都白搭。

说实话，我们更希望你选技术这条路。 不是因为你走不了艺考，而是未来10年是智能制造的天下。
有一门硬技术在手，到哪都能挣高薪。这个行业不看背景、不看出身，只看你有没有真本事。
几年后你穿着工装、在中控室调试设备、拿着同龄人羡慕的薪水——那种感觉，比走红毯踏实。
